# Bootstrap Confidence Intervals

Non-parametric bootstrap method for estimating confidence intervals of the sample mean.

## Method Source

- Paper: *An Introduction to the Bootstrap* (1993)
- Authors: Bradley Efron, Robert J. Tibshirani

## Requirements

```bash
pip install numpy scipy
```

## Usage

```bash
python src/bootstrap.py
```

## Structure

- `src/` - Main implementation
- `scripts/` - Helper scripts
- `simulation/` - Simulation studies
- `data/` - Input data
- `results/` - Output results
- `tests/` - Unit tests
