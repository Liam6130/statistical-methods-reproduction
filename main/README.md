# Statistical Methods Repository

A collection of statistical method implementations and reproductions from academic literature.

## Directory Structure

Each sub-project is contained in its own directory under this folder.

## Adding New Methods

1. Copy `project_template` to a new directory: `cp -r project_template/ my_new_method/`
2. Implement your statistical method in `src/`
3. Add any simulation code in `simulation/`
4. Document in `docs/` (not uploaded by default)
